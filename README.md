# Missche Dress Rentals

A responsive, static storefront concept for a special-occasion dress rental shop. Browse the collection, filter by occasion, and send a rental inquiry; the owner dashboard lets you review inquiries and update dress availability.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. The page uses remote Unsplash photos and Google Fonts.

## Demo behavior

Rental inquiries and availability changes are stored in the current browser's local storage. The dashboard is a front-end demo only: it has no login, server, email delivery, booking confirmation, or payment processing. Do not enter real customer information.
